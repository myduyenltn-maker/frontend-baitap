# MyStudy - Bài tập Front End

Website giới thiệu góc học tập, được xây dựng bằng:
- HTML: cấu trúc nội dung
- CSS: bố cục và giao diện responsive
- JavaScript: nút hiển thị lời động viên

## Chạy thử
Mở file `index.html` bằng trình duyệt.

## Deploy
Có thể triển khai bằng GitHub Pages hoặc Vercel.
